# Little Eyes

A cozy portrait optometrist tycoon. Choose one of two furnished clinics and a trial-frame or manual-phoropter starter, welcome patients, earn coins and XP, unlock equipment, and make the practice your own.

## Download from GitHub

Open [Build Little Eyes](https://github.com/Palview/Little-Eyes/actions/workflows/build-game.yml), select the latest successful run, and download **Little-Eyes-Game** under **Artifacts** (sign in to GitHub if required). Extract the ZIP, then open `Little-Eyes-Portrait.html` in Chrome. Each build runs the regression checks before uploading the game. The standalone HTML is generated by this workflow rather than stored in Git.

The repository contains the complete web source and original artwork. GitHub's **Code → Download ZIP** downloads the source; the runnable standalone is the Actions artifact above. A repository page is not a hosted game.

## Play

Download `Little-Eyes-Portrait.html` and open it in a JavaScript-capable browser such as Chrome. It contains all artwork and code, so it works offline after downloading. A phone's attachment preview may block JavaScript; open the downloaded file in the browser. The game fills the available portrait screen; its fullscreen button uses browser support.

Choose a practice, then a starter kit. Tap Level/XP for milestones, Equipment for purchases or free kit selection, and a furnishing for its status and free unlocked styles. Build pauses care while placing, moving, rotating or restyling objects. Preview all changes together; Confirm applies them once, and Cancel discards them. Rotate with the forward/reverse controls or R/Shift+R. Floor furniture has four views; mounted prints stay fixed to the wall. Layout, ownership and progression save on this device when browser storage is available. Keep the page open if a session-only notice appears.

## Source

`dist/index.html`, `styles.css`, `app.mjs`, `tycoon/` and `assets/` form the buildless web game. Serve `dist/` with a static HTTP server for development. All original generated atlases and crop/alpha-mask metadata are included. `docs/furniture-customization-release-notes.md` documents the current controls, v4 migration, art coverage and verification limits. `docs/progression-release-notes.md` retains equipment balance details.

Node checks: `node scripts/check-tycoon.mjs`. Rebuild standalone HTML: `node scripts/package-standalone.mjs`. Native visual proofs use the installed `@napi-rs/canvas` dependency with `node scripts/render-station-proof.mjs`; sprite registration reads original PNGs with Pillow, without editing their pixels. The source ZIP includes the approved design/plan, original assets, tests and production-rendered proofs.

The Play Store/Android app release remains separate. This deliverable is a browser game. Physical-phone/browser layout and performance checks are still needed because browser startup was blocked in the build sandbox. Hosting was not published because the existing source repository connection failed.
